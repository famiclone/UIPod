# UIPod — User Manual & About

Version: v0.4.0
Target: TrimUI Brick / Hammer (tg5040, NextUI, 1024x768 HiDPI)
Repository: github.com/famiclone/UIPod

UIPod is an iPod Mini-inspired offline, Navidrome, and Jellyfin media player built on a customized Rockbox audio core with a pure-Rust OpenGL ES GPU UI engine, 4-shade monochrome themes, AutoEQ headphone profiles, Bayer-dithered 4-shade GPU audio visualizers, and native Rust (.uipod) games & utilities.

## 1. Global Controls

• D-Pad Up / Down — Navigate lists and menus (hold to fast-scroll)
• D-Pad Left / Right (or L1 / R1) — Page up / down in lists; previous / next track on Now Playing (hold to seek)
• A — Select / Open item; Play / Pause on Now Playing
• Hold A — Open context menu on tracks, albums, folders, or playlists
• B — Go back one screen
• Hold B — Return directly to the Main Menu from anywhere
• START — Play / Pause music globally (or open Pause Menu inside games)
• MENU — Context menu; on Main Menu opens Settings; in Text Viewer opens Reader Options
• VOL + / VOL - — Adjust volume (40 perceptual loudness steps, works even with screen off or locked)
• SELECT + VOL + / VOL - — Adjust screen brightness anywhere
• L2 / R2 — Previous / Next chapter in .m4b audiobooks & cuesheets; skip tracks in Sound Racer
• Side Switch — Input Hold / Lock (volume rocker stays active without waking the screen)

## 2. Media Library & Sources

UIPod merges local SD-card folders and your personal streaming servers into a single deduplicated SQLite library (Artists, Albums, Genres, Songs, Playlists, Podcasts, Audiobooks, Videos):

• Local SD Card — Browse serves as the first Main Menu item with persistent last-opened directory memory and file management context menu (Hold A / MENU -> Play, Add to Playlist, Delete, Rename, Copy, Move, and Info opened in Text Viewer). Watched library folders are configured under Settings -> Library (supports FLAC, MP3, Opus, Ogg Vorbis, AAC/M4A, ALAC, WAV, WavPack, APE, .m4b chapters, .cue sheets, and H.264/MP4 videos).
• Navidrome / Subsonic — Configure server URL, username, and password under Settings -> Sources -> Navidrome. Supports streaming, automatic sliding-window queue prefetching, scrobbling, Navidrome Favourites playlist, and offline pinning.
• Jellyfin — Configure under Settings -> Sources -> Jellyfin. Supports music libraries plus Movies and TV Shows (direct-streaming compatible 8-bit H.264/MPEG4 on hardware CedarX and automatically transcoding HEVC/10-bit/4K/DTS on the server).
• Offline Mode — Toggle Settings -> Offline Mode to browse and play strictly local and already-downloaded media without network requests.
• Downloads Queue — Press Hold A / MENU -> Download on any remote track, album, or video to save it permanently to /mnt/SDCARD/Media/. Monitor or manage active transfers in Extras -> Downloads (live DONE/TOTAL progress also appears in the top bar).

## 3. Appearance, Themes & Transitions

Open Settings -> Appearance (Display) to customize the visual experience:

• 4-Shade Theme Presets — Authentic iPod Mini / Classic monochrome palettes plus UIPod Classic Dark.
• Customize Theme — Enter custom HEX colors; intermediate shades (fg1, fg2) are automatically derived.
• Monochrome Album Art — Quantizes and Bayer-dithers cover art into the 4 shades of your active theme (toggleable to full-color 24-bit RGB).
• Screen Transitions — Choose between Slide, Cover, Fade, Pixels, Blinds, or Off.
• Main Menu Items — Show or hide Main Menu entries (Browse is enabled first by default for full SD-card file management, alongside Library facets and Shuffle All).
• Language — English and Ukrainian UI localization.

## 4. Sound, Equalizer & AutoEQ

Open Settings -> Sound for studio-grade Rockbox 32-bit DSP processing:

• Equalizer & AutoEQ — 10-band parametric equalizer with a built-in searchable offline AutoEQ headphone database (thousands of IEM and over-ear targets), custom .cfg presets in uipod/eqs/, Precut anti-clipping, and Simple / Advanced band tuning.
• Effects — Real-time creative DSP submenu featuring:
  - Speed (Texture Warp) — 6-voice granular time-stretching (from 1/16x ultra-slow ambient drone up to 1.5x) with adaptive grain size and Flux shimmer so any song can become an ambient soundscape without pitch drop.
  - Tape Mode — Full Walkman cassette transport & analog tape submenu with independent controls for Enable, Wow & Flutter (pitch swimming), Tape Hiss, Tape Crinkles (mylar folds & spacing-loss dropouts), Saturation & Head-Bump, HF Roll-Off, Stop / Start FX (motor spin-down on Pause & spin-up on Resume), and Seek Motor Sound (electro-mechanical motor & spool whir when fast-forwarding/rewinding).
• ReplayGain — Automatic track or album loudness normalization with clipping prevention.
• Balance, Channels & Crossfeed — L/R channel balance, mono/swap routing, and Meier headphone crossfeed for vintage stereo recordings.
• Menu Click — Authentic iPod-style tactile click sound when scrolling menus and adjusting inline settings.
• Audio Outputs — Automatic hot-switching between internal speaker, 3.5mm headphone jack, USB-C DACs, and Bluetooth A2DP headphones (paired in NextUI).

## 5. Extras & Native Plugins (.uipod)

Open Extras -> Plugins to launch native 60 FPS GPU-accelerated Rust plugins:

• Games (exit & options via START / MENU):
  - Music Quiz — Classic iPod-style "Name That Tune" game! Plays a random mid-song snippet from your local SD-card library with 4 choices ("Artist - Track"). Pick with Up/Down + A (+1 point per right answer), press X for another snippet, or START/MENU for timer & round options.
  - Sound Racer — Real-time 3D rhythm highway generated directly from the currently playing song (including PCM audio and .nsf / chiptune / tracker formats)! Choose "Start song from beginning" or "Continue" on launch. Steer with Left/Right (or L1/R1), jump spikes with A, cash in clusters with B, skip songs with L2/R2, and pause game + music with START. Analyzed song maps (.bin) are cached automatically, and per-song Hi-Scores are recorded when you complete a track from beginning to end.
  - Tetris — Guideline 7-bag Tetris with SRS wall kicks, ghost piece, hold piece, and high scores.
  - Snake — Smooth arcade Snake with speed scaling and Classic / Wrap wall modes.
  - Brick Breaker — Arkanoid-style paddle & multi-brick arcade game.
  - 2048 — Sliding tile puzzle with automatic board state persistence.
• Apps & Demos (exit directly with B):
  - Stopwatch — Precision millisecond lap timer.
  - LCD Plasma — 60 FPS 4-shade procedural demoscene shader effect.
• Viewers:
  - Text Viewer — Opens .txt, .lrc, .md, .log, .cfg, .ini, .json, .cue, and .nfo files from Browse. Press X to cycle font size, MENU for bookmarks/jump/line spacing, START to play/pause music, and B to save your reading position and exit.

Custom third-party .uipod plugins can be installed by placing compiled .uipod files into /mnt/SDCARD/Plugins/UIPod/.

## 6. Visualizers, USB MTP & Device Power

• 4-Shade Audio Visualizers — Built-in Bayer-dithered GPU presets including Cassette Deck, Analog Stereo VU Meter, Sonic Vortex, Phosphor Scope, Spectrum Matrix, and LCD Plasma (Settings -> Visualizers or Now Playing -> Start Visualizer), rendered strictly in your active 4-shade theme palette and synced to speaker/Bluetooth latency. Press Left/Right to skip tracks (hold to rewind/fast-forward), L2/R2 to switch visualizer presets, X to toggle 4x4/2x2 LCD pixel grain, START to play/pause, and B to exit.
• USB MTP File Transfer — Plug in a USB-C cable to your computer while UIPod is running to mount /mnt/SDCARD over MTP without stopping playback.
• Device & Battery Care (Settings -> Device) — Configure Auto Screen Off, Sleep Timer (deep suspend-to-RAM), CPU Governor (Powersave / Dynamic / Performance), and AXP2202 Battery Charge Limit (75%–95%).
