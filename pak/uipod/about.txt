# UIPod — User Manual & About

Version: v0.10.0
Target: TrimUI Brick / Hammer (tg5040, NextUI) & Android Handhelds (arm64-v8a)
Repository: github.com/famiclone/UIPod

UIPod is an iPod Mini-inspired offline, Navidrome, and Jellyfin media player built on a customized Rockbox audio core with a pure-Rust OpenGL ES 3.0 GPU UI engine, dynamic native-HiDPI multi-screen layout (16:9, 16:10, 3:2, 4:3, 1:1, and portrait), 4-shade monochrome themes, AutoEQ headphone profiles, Bayer-dithered 4-shade GPU audio visualizers, and native Rust (.uipod) games & utilities.

## 1. Global Controls

• D-Pad Up / Down (or Left Stick) — Navigate lists and menus (hold to fast-scroll)
• D-Pad Left / Right (or L1 / R1) — Page up / down in lists; previous / next track on Now Playing (hold to seek)
• A — Select / Open item (shows a non-blocking floating HUD toast if Now Playing has nothing to resume); Play / Pause on Now Playing; Confirm on floating HUD confirmation cards
• Hold A — Open context menu on tracks, albums, folders, or playlists; in Text Viewer opens Reader Options
• B — Go back one screen; Cancel on floating HUD confirmation cards
• Hold B — Return directly to the Main Menu from anywhere
• START — Play / Pause music globally (or open Pause Menu inside games)
• MENU / Handheld Mode / Back Button — Context menu; on Main Menu opens Settings; in Text Viewer opens Reader Options
• VOL + / VOL - — Adjust volume (40 perceptual steps on TrimUI Brick; synced with hardware STREAM_MUSIC on Android)
• SELECT + VOL + / VOL - — Adjust screen brightness anywhere; solo SELECT toggles Paginated / Scroll mode in Text Viewer
• L2 / R2 — Previous / Next chapter in .m4b audiobooks & cuesheets; switch visualizer presets; skip tracks in Text Viewer, Beat Stack, Sound Racer & Pulsar Vanguard
• Side Switch — Input Hold / Lock (volume rocker stays active without waking the screen)

## 2. Media Library & Sources

UIPod merges local SD-card folders and your personal streaming servers into a single deduplicated SQLite library (Artists, Albums, Genres, Songs, Playlists, Podcasts, Audiobooks, Videos):

• Local SD Card — Browse serves as the first Main Menu item with persistent last-opened directory memory and file management context menu (Hold A / MENU -> Play, Add to Playlist, Delete, Rename, Copy, Move, and Info opened in Text Viewer). Watched library folders are configured under Settings -> Library (supports FLAC, MP3, Opus, Ogg Vorbis, AAC/M4A, ALAC, WAV, WavPack, APE, .nsf/.nsfe NES/Famicom chiptunes with 2A03/VRC6/MMC5 expansion chips, Music & SFX subtrack browser, live Now Playing APU channel meters, Hold A -> Channels mute/solo mixer, and Endless Loop, .gsf/.minigsf GBA music, .mid/.midi/.kar/.rmi MIDI with built-in Mobile_0100_base.sf2 and custom .sf2 SoundFonts configured in Settings -> Library -> SoundFont Folders and selectable via Hold A -> SoundFont on MIDI tracks, .m4b chapters, .cue sheets, and H.264/MP4 videos).
• Navidrome / Subsonic — Configure server URL, username, and password under Settings -> Sources -> Navidrome. Supports streaming, automatic sliding-window queue prefetching, scrobbling, Navidrome Favourites playlist, and offline pinning.
• Jellyfin — Configure under Settings -> Sources -> Jellyfin. Supports music libraries plus Movies and TV Shows (direct-streaming compatible 8-bit H.264/MPEG4 on hardware CedarX and automatically transcoding HEVC/10-bit/4K/DTS on the server).
• Video Player Controls & Subtitles — During local or Jellyfin video playback, press Hold A / MENU to open Video Settings (pausing playback cleanly behind the menu): switch Aspect Fit (Fit / Stretch, or press X during playback), select embedded Audio Tracks, and toggle embedded or sidecar .srt Subtitles.
• Last.fm Scrobbling (Settings -> Accounts -> Last.fm) — Sign in quickly via on-screen QR Code (or username/password / custom API keys in lastfm.cfg). Supports real-time Now Playing status, local & streaming scrobbling, and a persistent offline scrobble cache that automatically syncs when back online.
• ListenBrainz Scrobbling (Settings -> Accounts -> ListenBrainz) — Enter your ListenBrainz User Token in-app or via listenbrainz.cfg (and optionally a custom Server URL for self-hosted Maloja or Koito instances). Supports live Now Playing updates, local/chiptune/streaming scrobbling, and an independent persistent offline scrobble cache that syncs concurrently alongside Last.fm.
• Offline Mode — Toggle Settings -> Offline Mode to browse and play strictly local and already-downloaded media without network requests.
• Downloads Queue — Press Hold A / MENU -> Download on any remote track, album, or video to save it permanently to /mnt/SDCARD/Media/. Monitor or manage active transfers in Extras -> Downloads (live DONE/TOTAL progress also appears in the top bar).

## 3. Appearance, Themes & Transitions

Open Settings -> Appearance (Display) to customize the visual experience:

• 4-Shade Theme Presets — Authentic iPod Mini / Classic monochrome palettes plus UIPod Classic Dark.
• Customize Theme — Enter custom HEX colors; intermediate shades (fg1, fg2) are automatically derived.
• Monochrome Album Art — Quantizes and Bayer-dithers cover art into the 4 shades of your active theme (toggleable to full-color 24-bit RGB).
• Screen Transitions — Choose between Slide, Cover, Fade, Pixels, Blinds, or Off.
• Main Menu Items — Show or hide Main Menu entries (Browse is enabled first by default for full SD-card file management, alongside Library facets and Shuffle All).
• Language — English and Ukrainian UI localization, with built-in Noto Sans CJK & Noto Serif CJK vector fallbacks for Ukrainian Cyrillic, Japanese, Chinese, and Korean text.

## 4. Sound, Equalizer & AutoEQ

Open Settings -> Sound for studio-grade Rockbox 32-bit DSP processing:

• Equalizer & AutoEQ — 10-band parametric & GPU Graphic Equalizer (Preamp + 10 vertical band sliders with X-button quick Bypass), built-in searchable offline AutoEQ headphone database (thousands of IEM and over-ear targets), custom .cfg presets in uipod/eqs/, and Precut anti-clipping.
• Effects — Real-time creative stereo DSP suite with a master Enable Effects switch (also accessible from the Now Playing context menu, indicated by the FX header badge):
  - Speed (Texture Warp) — 6-voice granular time-stretching (from 1/16x ultra-slow ambient drone up to 1.5x) with adaptive grain size and Flux shimmer so any song can become an ambient soundscape without pitch drop.
  - Tape Mode — Full Walkman cassette transport & analog tape submenu with independent controls for Enable, Wow & Flutter (pitch swimming), Tape Hiss, Tape Crinkles (mylar folds & spacing-loss dropouts), Saturation & Head-Bump, HF Roll-Off, Stop / Start FX (motor spin-down on Pause & spin-up on Resume), and Seek Motor Sound (electro-mechanical motor & spool whir when fast-forwarding/rewinding).
  - Reverb — Stereo algorithmic room/hall reverb with Size, Damping, Pre-Delay, Width, and Mix.
  - Delay — Stereo / Ping-Pong echo with Delay Time, Feedback, Tone filter, Ping-Pong toggle, and Mix.
  - Chorus — Lush stereo modulation with Rate, Depth, and Mix.
  - Flanger — Resonant jet-sweep flanger with Rate, Depth, Feedback, and Mix.
• Crossfade & Auto-DJ — Dual-Deck Smart DJ transition engine with Off, Classic, DJ Vinyl (cubic pitch resampler), and DJ Master Tempo (pitch-preserving stereo WSOLA) modes, 4 Bars / 8 Bars / 12s transition lengths, ±6% / ±10% / ±12% max tempo stretch (with 0.5x/2x octave folding and native .nsf tick-rate sync), Equal-Power center-phrase Bass Swap (20 Hz <-> 250 Hz), automatic DJ Filter Wash + Ping-Pong Tail fallback on incompatible BPMs, Keep Album Gapless protection, Quick Cut on Next (single R1 tap = ~2s DJ Filter Fade, double-tap R1 = instant cut), and a live Now Playing status pill (DJ SYNC / DJ WASH / FADE).
• ReplayGain — Automatic track or album loudness normalization with clipping prevention.
• 3.5mm Low-Shelf & Direct DAC (hw:0,0) — Optional wired headphone bass compensation (Off, Subtle +2.5 dB, Warm +4.0 dB, Deep +6.0 dB) for AC-coupled 3.5mm jacks, plus Direct DAC (hw:0,0) hardware ALSA output bypassing software dmix.
• Balance, Channels & Crossfeed — L/R channel balance, mono/swap routing, and Meier headphone crossfeed for vintage stereo recordings.
• Menu Click — Authentic iPod-style tactile click sound when scrolling menus and adjusting inline settings.
• Audio Outputs — Automatic hot-switching between internal speaker, 3.5mm headphone jack, USB-C DACs, and Bluetooth A2DP headphones (paired in NextUI).

## 5. Extras & Native Plugins (.uipod)

Open Extras -> Plugins to launch native 60 FPS GPU-accelerated Rust plugins:

• Games (exit & options via START / MENU):
  - Music Quiz — Classic iPod-style "Name That Tune" game! Plays a random mid-song snippet from your local SD-card library with 4 choices ("Artist - Track"). Pick with Up/Down + A (+1 point per right answer), press X for another snippet, or START/MENU for timer & round options.
  - Sound Racer — Real-time 3D rhythm highway generated directly from the currently playing song (including PCM audio and .nsf / chiptune / tracker formats)! Choose "Start song from beginning" or "Continue" on launch. Steer with Left/Right (or L1/R1), jump spikes with A, cash in clusters with B, skip songs with L2/R2, and pause game + music with START. Analyzed song maps (.bin) are cached automatically, and per-song Hi-Scores are recorded when you complete a track from beginning to end.
  - Pulsar Vanguard — Cosmic Galaga-inspired swarm shooter with monotonic bar-phase music auto-attack! Steer with Left/Right (or L/R), switch 1/4 Beat Pulse and 1/1 Wave Cannon with Y, hold A for 1/8 Focus Vulcan spread, dash with B/X (±65 ms on-beat triggers Perfect Phase + EMP), and skip tracks with L2/R2.
  - Beat Stack — Music-synced 4-color Siemens Stack Attack rhythm-puzzle game! Overhead cranes drop 4 distinct crate types on the live track's beat grid (with a 120 BPM fallback clock when paused/silent). Walk and push single crates with Left/Right, jump vertically with B, leap diagonally onto crates with B + Left/Right or L1/R1, toggle the rules hint with X, skip tracks with L2/R2, and form 2x2+ same-color clusters or full 12-wide floor rows (MONO ROW x3 for single-color rows) that arm immediately and detonate on the next strong beat (Beats 1 & 3) for CHAIN cascades.
  - Tetris — Guideline 7-bag Tetris with SRS wall kicks, ghost piece, hold piece, and high scores.
  - Snake — Smooth arcade Snake with speed scaling and Classic / Wrap wall modes.
  - Brick Breaker — Arkanoid-style paddle & multi-brick arcade game.
  - 2048 — Sliding tile puzzle with automatic board state persistence.
• Apps & Demos (exit directly with B):
  - Stopwatch — Precision millisecond lap timer.
  - LCD Plasma — 60 FPS 4-shade procedural demoscene shader effect.
• Viewers:
  - Text Viewer (E-Book & Document Reader) — Opens .epub, .fb2, .fb2.zip (UTF-8 & Windows-1251), DRM-free .mobi/.prc/.azw, .md, .txt, .lrc, .log, .cfg, .ini, .json, .cue, and .nfo files from Browse, complete with 4-shade Bayer-dithered book covers & illustrations, interactive Footnote popup cards (short-tap A to open/cycle, Up/Down to scroll, B to dismiss), and a permanent full-width bottom progress bar (% or READ / TOTAL pages). Press solo SELECT to toggle Paginated (Left/Right) vs Infinite Scroll (Up/Down) at the exact same reading spot, MENU or Hold A for Reader Options (Chapters / Table of Contents, Reading Mode, Font switching between Geologica Sans and Noto Serif with full Ukrainian Cyrillic + CJK support, Font Size, Line Spacing, Hide UI top header toggle, Progress Label, Go to Beginning, Go to End, Exit), X to cycle font size, START to play/pause music, L2/R2 for previous/next music track, and B to save reading progress and exit.

Custom third-party .uipod plugins can be installed by placing compiled .uipod files into /mnt/SDCARD/Plugins/UIPod/.

## 6. Visualizers, USB MTP & Device Power

• 4-Shade Audio Visualizers — Built-in Bayer-dithered GPU presets including Cassette Deck, Analog Stereo VU Meter, Sonic Vortex, Phosphor Scope, Spectrum Matrix, and LCD Plasma (Settings -> Visualizers or Now Playing -> Start Visualizer), rendered strictly in your active 4-shade theme palette and synced to speaker/Bluetooth latency. Press Left/Right to skip tracks (hold to rewind/fast-forward), L2/R2 to switch visualizer presets, X to toggle 4x4/2x2 LCD pixel grain, START to play/pause, and B to exit.
• USB MTP File Transfer — Plug in a USB-C cable to your computer while UIPod is running to mount /mnt/SDCARD over MTP without stopping playback.
• Device & Battery Care (Settings -> Device) — Configure Auto Screen Off, Sleep Timer (deep suspend-to-RAM), CPU Governor (Powersave / Dynamic / Performance), and AXP2202 Battery Charge Limit (75%–95%).
