Installation

TG5040 · UIPod.pak.zip

TrimUI Brick / Hammer (NextUI)

  1. Download UIPod.pak.zip from GitHub Releases or install via NextUI Pak Store.
  2. Extract UIPod.pak to /mnt/SDCARD/Tools/tg5040/UIPod.pak.
  3. Open Tools → UIPod. Plug in USB-C anytime for MTP file transfer without stopping playback.
Android 8.0+ · arm64-v8a APK

Android Handhelds (arm64-v8a)

  1. Download UIPod-__UIPOD_VERSION__-android-arm64.apk from GitHub Releases (Android 8.0+ / API 26+).
  2. Install the APK on your Retroid, Odin, Anbernic, Ayaneo, or gamepad-equipped device.
  3. Grant media storage access to scan local folders, or configure Navidrome / Jellyfin in Settings → Sources.
